# Sağlayıcıya gerçek mesaj testi

Uygulamada **Ajan merkezini aç → Gerçek mesaj testi** bölümünü kullanın. Codex için mesaj alanına `Selam` yazıp gönderin. OpenCode seçildiğinde varsayılan bağlantı **Etkileşimli terminal**, model **opencode/space-bunny-free** olur. **OpenCode terminalini aç** düğmesine basın; native ekran hazır olunca terminale `Selam` yazıp Enter'a basın. Config veya gerçek proje gerekmez; demo içinde de bağlı CLI hesabı kullanılır ve sağlayıcıya göre ücret/kota tüketebilir.

OpenCode için ayrıca **CLI run · tek mesaj** ve **HTTP Server · tek mesaj** yolları seçilebilir. Bunlar aynı erişim yetkisini garanti etmez: yerel doğrulamada Space Bunny Free etkileşimli TUI'da yanıt verirken `opencode run --format json` 403 verdi. Server ile Big Pickle da 403 vermişti. Bu ayrım otomatik fallback veya istemci kimliği/başlık değişikliğiyle aşılmaz. Kısıtla karşılaşırsanız native terminali ya da o bağlantıya izin veren başka bir modeli kullanın. Boş model alanı OpenCode'un genel varsayılanına döner; bu makinedeki genel varsayılan erişilemeyen yerel modele gidiyordu.

Tek mesaj yollarında her gönderim bağımsızdır; önceki mesajlar bağlam olarak eklenmez. En fazla 2000 karakter gönderilir. Yanıt veya hata aynı panelde gösterilir; başarılı yanıtta geçen süre belirtilir. Model çağrısı en fazla 90 saniye sürer. İptal düğmesi veya panelin kapatılması aktif isteği iptal eder. Test sürerken yeni test, ajan başlatma, bağlantı kontrolü ve proje değiştirme engellenir. Uygulama kapanırken de test iptal edilir. Otomatik yeniden deneme/farklı model deneme yapılmaz.

Native terminalde ise OpenCode'un kendi devam eden konuşması, model seçimi ve izin ekranları kullanılır; 90 saniyelik tek mesaj sınırı uygulanmaz. **OpenCode oturumunu kapat**, ajan merkezi kapatma ve uygulama çıkışı sahipli PTY'yi durdurur. Terminal proje dışındaki sahipli geçici dizinde açılır; kullanıcı hesabının normal yetkileri geçerlidir. Yerel dosya/araç işlemleri için AgentMesh deny-all politikası uygulanmaz; native OpenCode kararlarını kullanıcı yönetir. Açık PTY varken ajan başlatma/birleştirme ve proje değiştirme mevcut terminal kurallarıyla engellenir. Oturum kapanınca geçici dizin temizlenir; OpenCode kendi yerel geçmişini saklayabilir. Native terminal çıktısı maskelenmez ve AgentMesh journal'a yazılmaz.

Tek mesaj testlerinde de proje yerine sahipli geçici dizin kullanılır; proje dosyaları mesaja eklenmez. Codex App Server ephemeral thread, `read-only` sandbox, `never` approval, kapalı shell/web search ve kısa sohbet talimatıyla açılır; tüm izin istekleri reddedilir. OpenCode Server yalnızca deny-all izinli ayrı test session açar. CLI run yolu geçici inline config'te deny-all yetkili ayrı mesaj ajanını seçer; mevcut inline sağlayıcı ayarları korunur. Başarı yalnızca metin ve tamamlanmış `step_finish/stop` olayıyla kabul edilir; JSON hata olayı ve eksik bitiş başarı sayılmaz. Server session'ı silinmeye çalışılır, sahipli süreç kapatılır ve geçici dizin kaldırılır. İptal/kopma sırasında native sağlayıcı geçmişinde kayıt kalabilir. Bu akış genel OS izolasyonu garantisi değildir; sağlayıcı hesabı ve kullanıcı genel CLI ayarları kullanılır.

Prompt ve yanıt AgentMesh journal/context/mesaj geçmişine yazılmaz. Yanıt maskeleme ve görüntüleme sınırından geçer. OpenCode hata görünümü yalnızca hata mesajı/HTTP kodu ve varsa yerel servis adresini gösterir; ham HTTP başlıkları, response body veya sağlayıcı metadata'sı aktarılmaz. Sağlayıcı kendi hizmetinde mesajı işleyebilir/saklayabilir. **Bağlantıları kontrol et** düğmesi ayrı kalır: model çağırmaz ve başarılı mesaj testinin yerine geçmez.

## 18 Ekim 2026 yerel sonuçları

- Codex 0.159.2: gerçek kısa selamlama isteği → `Selam!`, yaklaşık 5.5 saniye. App Server thread başlangıcında native sandbox enum'u `read-only`/`workspace-write`; turn policy türü `readOnly`/`workspaceWrite`. Önceki taklit testte thread enum'u yanlış biçimde bekleniyordu; native doğrulamayla düzeltildi.
- OpenCode 1.19.3, model seçilmeden: yerel `127.0.0.1:11434` hedefi bağlantı hatası verdi. CLI/sunucu erişilebilir olsa da bu varsayılan modelin inference servisine erişilemiyor.
- OpenCode `opencode/big-pickle`: sağlayıcı HTTP 403 ile isteği reddetti ve ücretsiz katmanın OpenCode içinden kullanılmasını istedi. Bu kısıt aşılmaya çalışılmadı; başka yapılandırılmış model/sağlayıcı seçilmeli. Bu ilk Server denemesinde başarılı yanıt alınmadı; sonraki native TUI sonucu aşağıdadır.
- Sonraki doğrulama: **opencode/space-bunny-free**, aynı yerel OpenCode 1.19.3'ün **etkileşimli TUI** yolunda `Selam` mesajına **Merhaba! Nasıl yardımcı olabilirim?** yanıtı verdi (native ekranda yaklaşık 3.8 sn). Aynı model CLI `run --format json` yolunda 403 verdi. Başarılı OpenCode generation artık TUI için doğrulandı; bu sonuç Server/run yollarına genellenmez.

Bu kayıtlar kod yazma, araç kullanma, session resume veya tüm modellerin/kotaların doğrulandığı anlamına gelmez. Bu kabul işleri CORE-008 kapsamında açık.

`npm test` geçici dizin temizliğini, iptal/tek istek kilidini, kayıt yapılmamasını, Codex salt okunur protokolünü, OpenCode deny-all/yanıt kimliği/hata/temizliği ve CLI süreç olaylarını doğrular. `npm run desktop:smoke` form ve IPC hata görünümünü sınar; bu modda gerçek tek-mesaj model çağrısı açıkça reddedilir. `npm run desktop:smoke:opencode-tui` ayrıca kurulu native OpenCode'u gerçek Electron/xterm içinde açar, Space Bunny Free ekranını ve kapanışı doğrular; mesaj göndermez.
